# exclude.txt -- 永远不参与「是否走旁路由」判断的地址段
#
# 这些段会被 gen-not-cn.awk 从补集里扣掉，也就是「始终直连」。
# 它们是安全边界：少一个内网段，内网互访就会被打标送去旁路由，包在路由器与
# 旁路由之间来回弹，最后被兜底 drop —— 症状是「内网服务全超时、上外网正常」。
#
# 所以这个文件：
#   - 只读展示，界面上不提供编辑入口
#   - 直接连白名单需求请加到 UCI 的 pbr-lite.direct.dst，不要动这里
#   - 改这里必须同步改 gen-not-cn.awk 里的兜底列表（文件读不到时用）
#
# 逐条含义：
#   0.0.0.0/8        本机地址 / 默认路由 / DHCP 里的 0.0.0.0
#   10.0.0.0/8       RFC1918
#   100.64.0.0/10    CGNAT（运营商级 NAT、部分 VPN 网段）
#   127.0.0.0/8      回环
#   169.254.0.0/16   link-local（APIPA）
#   172.16.0.0/12    RFC1918
#   192.0.0.0/24     IETF 协议分配
#   192.0.2.0/24     TEST-NET-1（文档用）
#   192.168.0.0/16   RFC1918（本 LAN）
#   198.18.0.0/15    基准测试用
#   198.51.100.0/24  TEST-NET-2
#   203.0.113.0/24   TEST-NET-3
#   224.0.0.0/4      组播（mDNS / SSDP / IGMP，打标会把设备发现功能搞挂）
#   240.0.0.0/4      保留 + 广播
